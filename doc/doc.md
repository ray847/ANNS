## Context

This is the project of curriculumn Fall 2025 Data Structures (H).

The goal of the project is to create a fast algorithm to search for neighbouring
vectors of an arbitrary vector from a set data base of vectors.

## Project Structure

Files & Folders:
* `doc\` Folder for all documentations.
    * `doc.md` General documentation. This is also the file you are looking at right now.
* `src\` Folder for all code files.
    * `Main.cpp` The main file that lauches tests on dataset.
    * `SolutionConcept.h` This file contains the requirement (a c++ concept) for a valid solution class.
        You can check if your class declaration is valid with this concept.
    * `...` Other source files.
* `data_o\` Folder for extracted vector data.
    * `glove\` The glove dataset.
        * `base.txt`
        * `query.txt` The query vector data generated by query generator.
    * `sift\` The sift dataset.
        * `base.txt`
        * `query.txt` The query vector data generated by query generator.
* `build\` CMake release (O2/O3) build files.
* `debug\` CMake debug build files.
* `data.tar.gz` Vector dataset provided.
* `CMakeLists.txt` Root CMake file. This should also be the only CMake file in this whol project.
* `.clangd` Configuration for the Clangd lsp.
